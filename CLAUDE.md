Astro static site for Hackley Tech Angels (hackleytechangels.org), a student tech club. Built from a Claude artifact; conventions follow ../judyrosenthal.com and ../lillyrosenthal.com, deploy layout follows ../log.lillyrosenthal.org.

- One page (src/pages/index.astro) holding five full-screen views: #home, #portfolio, #angels, #story, #contact, plus #thanks (shown after the contact form sends; not in the menu or scroll order, see EXTRA in site.ts). src/scripts/site.ts switches between them on the URL hash (so the sky and doves carry across), and also does the smooth wheel scrolling, "keep scrolling" into the next page, the nav dot and the portfolio section pills. Do not split the views into separate Astro pages without replacing that.
- Content lives in src/data: menu.ts (nav + page order + titles), portfolio.ts (official work case studies and personal project cards), angels.ts (members, portraits, portrait placement), story.ts (chapters), siteConfig.ts (site name, footer links, contact endpoint). Components in src/components render them; adding a project or member is a data edit plus an image in src/assets.
- All CSS is src/styles/global.css (global, no scoped component styles), kept close to the artifact's stylesheet. Entrance animation order is the `--i` custom property on `.st` elements.
- Images are in src/assets and go through astro:assets `<Image>` (WebP at build). The sky and dove sprite are CSS backgrounds referenced from global.css.
- Other scripts: src/scripts/nixie.ts (neon title), glass.ts (liquid-glass refraction on `.glass`, Chromium only), contact.ts (posts the form).
- Contact form: public/contact.php emails the message via public/mailer.php (dependency-free SMTP) to CONTACT_TO, using SMTP_* constants from config.local.php. That file is server-only (template: public/config.local.php.example) and also holds the webhook secret. There is no PHP under `astro dev`, so the form reports a send failure locally; test it with `php -S` against dist/ (see README).
- Deploy: push to main; public/gitwebhook.php runs ~/deploy/hackleytechangels.org.sh (a copy of deploy/hackleytechangels.org.sh kept outside the checkout), which builds and swaps the web root. After editing the deploy script, the server copy must be refreshed by hand.
- Git: do not commit, push, `git init` or add remotes; Brian reviews and commits himself.
- "Tech Angel" role lines, the story copy, the footer's Instagram/Website links and the "Terms & Policies" link are placeholders carried over from the artifact.
